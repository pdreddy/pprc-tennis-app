The expanded tests found and fixed backward-compatible verification handling, accessible invitation input labeling, invitation/schedule queries that needed permission-compatible scopes, emulator restart connection reuse in the persistence harness, and test fixture date/assertion mistakes. Test files sharing the same emulator project/rules now run serially. Score versions, denial assertions, concurrency scenarios and complete lifecycle checks remain enabled.

Group assignment can be audited/rebuilt before fixtures, and captain withdrawals automatically promote waiting registrations. After fixtures, only organizers can withdraw a team once remaining encounters are resolved/forfeited. Submitted lineups and downstream results remain locked. Storage administrative access also checks the PPRC club and event scope, including denial for an administrator from another club.

See [TRIACE operations](TRIACE.md), [schema/migration](SCHEMA_MIGRATIONS.md), [staging](STAGING.md), [remaining production readiness](PRODUCTION_READINESS.md), and [validation](VALIDATION.md). Local completion does not claim Firebase staging deployment, external-provider certification or a live public website.
